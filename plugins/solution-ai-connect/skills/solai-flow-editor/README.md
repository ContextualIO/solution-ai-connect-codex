# solai-flow-editor

Portable skill for editing live Contextual flows through the `ctxl-flow-editor` MCP server.

This repository is designed to work in two ways:

- installed directly as a standalone skill in a coding agent
- bundled in a coding-agent plugin at `skills/solai-flow-editor/`

The skill requires the `ctxl mcp serve` server to already be running in the user's terminal. The MCP server name expected is `ctxl-flow-editor`.
